# Nail Salon Website

A modern and elegant nail salon website concept designed and developed as a front-end practice project.

This project focuses on creating a clean, visually appealing interface for a beauty and nail salon, with an emphasis on layout, typography, color harmony, and user-friendly navigation.

##  Features

* Modern and elegant UI design
* Persian RTL layout
* Clean and organized page structure
* Navigation menu with smooth interactions
* Light/Dark mode toggle
* Service showcase section
* Image gallery section
* Appointment / reservation call-to-action
* Social media and contact section
* Hover effects and subtle animations
* Custom typography and cohesive color palette

##  Technologies

* HTML5
* CSS3
* JavaScript
* Font Awesome
* Figma

##  Design

The interface was first designed in Figma and then implemented using HTML, CSS, and JavaScript.

The design focuses on:

* Minimal and elegant visual style
* Soft and cohesive color palette
* Clear visual hierarchy
* Consistent spacing and typography
* Simple and intuitive user experience

##  Project Status

This is a **design and front-end practice project** created as a website concept for a fictional nail salon.

> Note: The current version is designed for desktop and has not yet been fully optimized for responsive layouts.
